## Built systems

- **[astack](https://github.com/aakashagg123/astack)** — a Claude Code skill router for builders who ship with intent. 44 slash commands cover the full build cycle: problem discovery, spec writing, TDD implementation, security review, and staged shipping. A growth pipeline for product managers and marketers rides on the same router. Everything dispatches through a single `/astack` command.
- **[gatsby](https://github.com/aakashagg123/gatsby)** — a pure-Python static compiler and knowledge-graph generator that powers the [AI Knowledge Graph](/learning-zone/): 405 nodes and 1,550 cross-references across 19 tracks, compiled and maintained with Claude Code. Read the source for the architecture.
