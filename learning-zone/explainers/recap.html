The through-line. Every system here is a pipeline of stages. Each stage has one job, one cost and one way to break. The same is true of running an AI product: a launch, a model change or an incident is a short series of decisions, each with a number behind it. When something goes wrong, the first useful question is: which stage was it?

Walk-away question: "For the AI system I work on, can I draw its stages, say what each one costs, and say which one fails first?"

Test yourself

  1. Which stage decides the wait before the first word of an answer?

    AnswerMostly the queue and prefill, which read the whole prompt. Decode sets the speed after that. (Inside one LLM request)

  2. A model gives the true next word a probability of 0.30. What is the loss, and what does training do about it?

    AnswerAbout 1.20. Backpropagation finds a direction for every weight, and training takes a small step that lowers the loss. (How a model learns)

  3. What does attention do that the feed-forward layer does not?

    AnswerAttention moves information between tokens. The feed-forward layer works on each token alone. (One token through a transformer)

  4. Why does a diffusion model start from noise?

    AnswerIt was trained to name and remove noise, so generation runs that skill backwards from static, guided by the prompt. The seed picks which noise. (How an image model draws)

  5. Where should permission rules for an agent's tools live, and why?

    AnswerIn code, in a gateway. A model can be talked out of instructions, and code cannot. (One agent run)

  6. Why filter retrieved documents before the model sees them?

    AnswerAnything in the model's input can leak through a clever question. Data that is never retrieved cannot leak. (Anatomy of a guardrailed request)

  7. An AI feature scores 92% on average, but one must-not-fail case fails. Do you ship?

    AnswerNo. A must-not-fail case blocks launch whatever the average says. (One AI feature, from idea to launch)

  8. A new model costs twice as much per token. Why can your bill rise by more than twice?

    AnswerThe new model may write longer answers, and output tokens cost more than input tokens: 5 times as much on Anthropic's current models. (One model change)

  9. Why can an AI feature on a flat per-seat price lose money on your best customers?

    AnswerEvery task costs tokens, so heavy users cost far more than light ones and pay the same price. (From one AI task to gross margin)

  10. An eval score drops 8 points. What do you check before looking for a cause?

    AnswerWhether the drop is larger than the error bar, ideally with a case-by-case comparison. Then slice the score to find where it fell. (One eval regression, traced to its cause)

  11. What replaces "given, when, then" in a spec for an agent?

    AnswerExamples of accepted and rejected results, a pass rate on a test set and must-not-fail cases. (One user story becomes an agent spec)

  12. The assistant is giving wrong answers and the cause is unknown. What do you do first?

    AnswerStop the harm with a fallback chosen in advance, such as a degraded mode. Diagnose after. (One AI incident, from alert to postmortem)
